# Carga de Balances

## Dependencias del sistema  

- [**Node 24.x**](https://nodejs.org/es/download/current)  

## Instalar backend  

- Ir al directorio: `cd backend/`  
- Instalar dependencias del backend: `npm i`  

## Levantar en modo Desarrollo  

- Ir al directorio: `cd backend/`  
- Ejecutar: `npm run dev`  
- Navegar a http://localhost:3000/
