Generador de Reportes de Balance

Página en desarrollo - Por vnatale52@gmail.com

Los archivos de datos - balhist.txt, cuentas.txt, nomina.txt e indices.xlsx - son cargados automáticamente, por esta aplicación, desde una carpeta frontend/data, que está en el hosting server. Cifras en miles de pesos.

Luego, define los filtros para generar el reporte.

Filtros de Datos

Filtros para el Reporte - Elige sólo una entidad (dado que falta aún realizar pruebas para más de una Entidad.)

Mantén presionado Ctrl (o Cmd en Mac) para seleccionar varias entidades.

Bonus 1 : Buscador simultáneo en varios archivos a la vez (de diversos formatos) de múltiples cadenas de texto a la vez (extrayendo el contexto que rodea al texto hallado)

Bonus 2 : Cálculo de los Intereses Compensatorios o Resarcitorios

Bonus 3 : Reportes de Gastos de Viáticos
